About ArthDrishti

AI-powered inventory demand forecasting and stock-risk analytics. Built as an end-to-end full-stack project.

What it does

Trained on historical sales and inventory, the system predicts next-week demand and flags High (stock-out), Medium, Overstocked (slow-moving) and Safe products. Each at-risk product gets a suggested reorder quantity and an action.

Everything runs locally: Node/Express backend (with MongoDB for auth, products, sales, snapshots, contact), a Python FastAPI ML microservice (XGBoost .pkl), and a multi-page vanilla HTML/CSS/JS frontend.

Tech stack

Frontend

  • Vanilla HTML, CSS, JavaScript
  • Chart.js
  • Responsive, mobile-friendly

Backend

  • Node.js, Express 5, Mongoose
  • MongoDB
  • Auth (scrypt + HS256)

ML service

  • FastAPI, Uvicorn
  • pandas, numpy, scikit-learn, xgboost, joblib

ML model

  • Gradient Boosting (XGBoost)
  • Time-based split, rolling/lags
  • Risk rules on top of forecast

API quick reference

Backend (http://localhost:3000/api): GET /health GET /stats/overview GET /products /products/:id /products/:id/history /categories POST /forecast /forecast/:id (via ML proxy) GET /risk, /top-demand POST /auth/login /auth/register /auth/logout /auth/me POST /contact POST /forecasts/snapshot, GET /forecasts/history (auth) GET /risk/history (auth) ML service (http://localhost:8000/docs): GET /health, /stats/overview, /products, /risk, /forecast, /forecast/batch, /top-demand
